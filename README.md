# 关键词搜索 Keyword Search

一个 SillyTavern 第三方扩展，用于在多种数据来源中搜索关键词并统计出现频次。

## 功能

- 搜索范围可勾选：**当前预设 / 世界书 / 当前角色卡 / 当前聊天 / 全部角色卡 / 全部聊天**
- 显示每个条目的命中次数与高亮上下文片段
- 顶部汇总总频次与命中条目数
- 支持「区分大小写」与「正则模式」
- 入口：聊天输入框旁的「魔棒菜单」→ 关键词搜索；或斜杠命令 `/kwsearch 关键词`

> 「全部角色卡 / 全部聊天」需扫描磁盘，数据量大时较慢，默认不勾选。

## 安装

1. 打开 SillyTavern，点顶部「扩展程序」（堆叠方块图标）。
2. 点 **安装扩展程序**。
3. 粘贴本仓库的 URL，点安装。
4. 刷新页面即可在魔棒菜单看到「关键词搜索」。

> 需要本机已安装 git。

## 兼容性

- 适配 SillyTavern 对话补全（Chat Completion）预设。
- 数据访问统一通过 `SillyTavern.getContext()`；若某来源搜不到结果，请按 F12 控制台中 `[keyword-search]` 的提示核对字段名。
