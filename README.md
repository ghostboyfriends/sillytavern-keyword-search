# 关键词搜索 Keyword Search

一个 SillyTavern 第三方扩展：在预设、世界书、角色卡、聊天记录中搜索关键词，统计出现频次，并能一键跳转到关键词所在位置。配有可自由切换的高级玻璃质感界面。

## 功能

### 搜索与统计
- 六类搜索范围，可任意勾选组合：**当前预设、世界书、当前角色卡、当前聊天、全部角色卡、全部聊天**。
- 频次统计：顶部显示总次数与命中条目数，每个来源与条目也有各自小计，并附带高亮的上下文片段。
- 支持「区分大小写」与「正则模式」（正则旁有 `?` 按钮，点开有通俗说明）。
- 「全部角色卡 / 全部聊天」需扫描磁盘，数据量大时较慢，默认不勾选。

### 点击跳转
四类「当前」结果可点击直接跳转到所在位置并高亮闪烁：
- **当前聊天** → 滚动定位到对应消息。
- **世界书** → 自动打开对应世界书并定位到该条目。
- **当前预设** → 打开对应提示词条目的编辑框。
- **当前角色卡** → 定位并聚焦对应字段（必要时自动打开「高级定义」）。

全局结果（全部角色卡 / 全部聊天）因涉及切换当前角色或载入其它聊天，暂不提供跳转。

### 历史与状态
- 最近 10 条搜索记录，可单条删除或一键清空，持久保存（刷新不丢）。
- 关闭后重新打开面板，自动恢复上次的关键词、勾选范围与搜索结果。

### 高级界面
- 玻璃拟态面板 + 珠宝色渐变背景，按钮按下有凹陷反馈。
- 10 套可切换配色：黑金、粉紫、红蓝、祖母绿、深海、月白、樱粉、落日，外加 **跟随酒馆主题**（读取你的主题强调色）和 **跟随时间**（白天亮色系 / 夜间暗色系）。
- 通过面板右上角的圆形色卡一键切换，所选主题自动保存。
- 适配手机窄屏，并支持系统「减少动效」无障碍设置。

## 安装

1. 打开 SillyTavern，点顶部「扩展程序」。
2. 点 **安装扩展程序**，粘贴本仓库 URL 安装。
3. 刷新页面即可。

> 需要本机已安装 git。

## 使用

- 打开聊天输入框旁的「魔棒菜单」→ 点 **关键词搜索**。
- 或在输入框直接输入斜杠命令：`/kwsearch 关键词`。

## 兼容性与数据访问

- 适配 SillyTavern 对话补全（Chat Completion）预设。
- 所有数据均通过稳定接口 `SillyTavern.getContext()` 读取；若某来源搜不到结果，请按 F12 控制台中 `[keyword-search]` 开头的提示核对字段名。
