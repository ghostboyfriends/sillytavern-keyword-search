# 关键词搜索 Keyword Search

一个 SillyTavern 第三方扩展：在预设、世界书、角色卡、聊天记录中搜索关键词，统计出现频次，并能一键跳转到关键词所在位置。配有可自由切换的高级玻璃质感界面。

## 功能

### 搜索与统计
- 多种搜索范围，可任意勾选组合：
  - **当前预设**、**世界书**、**指定世界书**（下拉选一本）、**当前角色卡**、**当前聊天**
  - **全部预设**、**全部角色卡**、**全部聊天**（全局范围，默认收起，点「全局」展开）
  - **正则脚本的「替换为」内容**：单独勾选 **全局 / 当前预设绑定 / 当前角色卡绑定**，三个来源不会混用；已停用脚本也能搜索。
- 勾选「当前角色卡」时，会一并搜索 **该角色绑定的世界书**（内嵌条目、主世界书、附加书）与 **该角色的全部聊天存档**，结果分组显示。角色卡搜索也包含**备用开场白**（alternate greetings）。
- 频次统计：顶部显示总次数与命中条目数，每个来源与条目也有各自小计，并附带高亮的上下文片段。
- 支持「区分大小写」与「正则模式」（正则旁有 `?` 按钮，点开有通俗说明）。
- 「全部角色卡 / 全部聊天」需扫描磁盘，数据量大时较慢，默认不勾选。

### 分类标签
搜索后，结果区上方会出现分类标签：**全部 / 预设条目 / 角色卡 / 世界书 / 聊天记录 / 正则替换内容**。点一下可只看该类，无结果的类别不会出现，空分组也不显示，结果一目了然。

### 点击跳转
结果可点击直接跳转到所在位置并高亮：
- **当前聊天** → 滚动定位到对应消息（高处 / 未渲染 / 被隐藏的楼层会自动加载后再定位）。
- **该角色聊天** → 点击自动打开对应聊天存档，并跳到具体楼层。
- **世界书 / 角色世界书** → 自动打开对应世界书并定位到该条目。
- **当前预设** → 打开对应提示词条目的编辑框。
- **全部预设** → 弹出**只读查看器**直接查看该条目内容（带高亮），**不会切换、不影响当前预设**；需要编辑时再点查看器里的「切换到此预设并编辑」，切换前会确认是否保存当前预设。
- **当前角色卡** → 打开并聚焦对应字段，并**选中第一处匹配、滚动到那一行**（必要时自动打开角色面板或「高级定义」）。

### 查找替换
点选项区的「替换」展开替换栏，输入替换词后点「查找可替换项」，会列出所有可替换目标（每条预设条目 / 每条消息 / 每个角色卡字段为一项，带命中数与高亮预览）。可**逐项勾选**或**全选**，再点「替换所选」。为安全起见，替换**仅作用于已勾选的当前数据范围和正则脚本来源**，遵循区分大小写 / 正则设置（正则可用 `$1` 反向引用）。替换前会弹窗确认，执行后直接保存——**操作无法自动撤销，建议先备份**。角色卡的**备用开场白**也可逐条替换（通过官方接口安全写回，无需打开面板）；高级定义里的其它字段若本次未打开过，相应替换会被安全跳过并提示。

### 正则脚本的「替换为」字段
- 点范围区的 **「正则脚本」** 展开独立分区，选择 **全局 / 预设 / 角色卡**，未选择的来源不会参与搜索或替换。
- 预设指当前 API 所选预设的绑定正则；角色卡指当前角色卡的绑定正则，不会扫描其它角色或预设。
- 搜索的是 `replaceString` 的原始文本，而不是执行正则后的输出；点击结果可只读查看全文。
- 替换预览明确显示来源、所属对象、脚本名称及替换前后内容，可以逐项取消勾选。
- **只改「替换为」**，保留脚本 ID、查找表达式、停用状态、执行位置、排序与其它字段。
- 普通文字模式下，替换输入中的 `$1`、`$&`、`{{match}}` 等会作为字面文本保留。勾选「正则模式」时，替换输入继续支持 JavaScript 捕获组语法（例如 `$1`）。
- 预览生成后切换角色 / 预设，或脚本被其它编辑器修改，会停止旧目标的替换并要求重新查找。
- 保存按来源执行；若一个来源失败，会明确说明已保存的部分，不会把整个批次报告为成功。
- 旧版酒馆缺少某个来源的安全接口时，该来源会禁用，不降级写入其他区域。

### 原文备份与预设保存保护
- 替换列表中的 **「备份原文」** 可下载所选目标的原文及正则脚本记录，文件仅保存在浏览器下载目录。
- 这是用于手动恢复的原文记录，**不是可以直接导入酒馆的整份预设文件**；不会跨来源自动恢复。
- 修改预设正文时提交完整预设，保留预设绑定正则、其它扩展字段、未选中正文和排序，不使用可能产生空对象的通用保存路径。
- 同时修改预设正文与其绑定正则时，只提交一次完整预设，避免后一次保存覆盖前一次修改。

### 历史与状态
- 最近 10 条搜索记录，可单条删除或一键清空，持久保存（刷新不丢）。
- 关闭后重新打开面板，自动恢复上次的关键词、勾选范围与搜索结果。

### 高级界面
- 玻璃拟态面板 + 珠宝色渐变背景，按钮按下有凹陷反馈。
- 10 套可切换配色：黑金、粉紫、红蓝、祖母绿、深海、月白、樱粉、落日，外加 **跟随酒馆主题**（读取你的主题强调色）和 **跟随时间**（白天亮色系 / 夜间暗色系）。
- 通过面板右上角的圆形色卡一键切换，所选主题自动保存；预设查看器也会跟随同一配色。
- 适配手机窄屏，并支持系统「减少动效」无障碍设置。

## 安装

1. 打开 SillyTavern，点顶部「扩展程序」。
2. 点 **安装扩展程序**，粘贴本仓库 URL 安装。
3. 刷新页面即可。

> 需要本机已安装 git。

## 使用

- 打开聊天输入框旁的「魔棒菜单」→ 点 **关键词搜索**。
- 或在输入框直接输入斜杠命令：`/kwsearch 关键词`。

## 兼容性与数据访问

- 适配 SillyTavern 对话补全（Chat Completion）预设。
- 数据通过 `SillyTavern.getContext()` 与酒馆原生的预设 / 正则脚本读写接口访问；若某来源搜不到结果，请按 F12 控制台中 `[keyword-search]` 开头的提示核对字段名。
